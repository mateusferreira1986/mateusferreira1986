# Portfólio · Mateus Ferreira

Página de portfólio de **Mateus Ferreira**, estudante de Ciência de Dados na Faculdade de Tecnologia de Adamantina (Fatec).

A página apresenta o projeto **Proposta de inovação tecnológica na administração penitenciária**, um estudo de viabilidade do uso de reconhecimento facial no controle de saída e retorno de presos autorizados ao trabalho externo.

## Sobre o projeto

- **Problema:** controle de saída e retorno de presos autorizados ao trabalho externo.
- **O que foi feito:** proposta de reconhecimento facial para automatizar a identificação e registrar os horários de saída e retorno.
- **Como foi feito:** pesquisa exploratória e documental, considerando aspectos tecnológicos, operacionais, custos, segurança da informação e proteção de dados biométricos.
- **Resultado esperado:** mais confiabilidade na identificação, registro automatizado, menos falhas nos registros manuais, melhor rastreabilidade e modernização da gestão penitenciária.

## Sobre a página

- Um único arquivo: `index.html`
- CSS dentro do próprio arquivo
- Sem bibliotecas externas e sem JavaScript
- Responsiva para celular, com modo escuro automático

## Como visualizar

Abra o arquivo `index.html` no navegador. Não precisa instalar nada.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub e envie `index.html` e `README.md` para a raiz dele.
2. No repositório, abra **Settings** e depois **Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/ (root)`, e salve.
4. Aguarde alguns minutos. O endereço da página aparece na mesma tela.

Se o repositório se chamar `mateusferreira1986.github.io`, a página fica em `https://mateusferreira1986.github.io`.
